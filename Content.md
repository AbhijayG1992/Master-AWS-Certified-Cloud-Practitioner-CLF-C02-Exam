# Introduction to Cloud Computing

## Overview
Cloud computing is a model defined by the National Institute of Standards and Technology (NIST) for providing on-demand network access to computing resources. These resources can be rapidly provisioned and released, offering services over the internet such as storage, processing power, software applications, and development platforms.

---

## Core Concepts
- **On-demand Access**: Provision and utilize resources like virtual machines, storage, and applications as needed, paying only for what is used.
- **Resource Pooling**: Shared pools of computing resources enable efficient utilization and scalability.
- **Elasticity**: Dynamic scaling of services to accommodate workload fluctuations without manual intervention.
- **Pay-as-you-go Pricing**: Users are billed based on actual resource usage, reducing upfront investments.

---

## Components of Cloud Computing

### Service Models
1. **Infrastructure as a Service (IaaS)**: Provides virtualized computing resources like virtual machines, storage, and networking. Example: AWS EC2, S3.
2. **Platform as a Service (PaaS)**: Offers platforms for developers to build and deploy applications without managing infrastructure. Example: AWS Elastic Beanstalk, Lambda.
3. **Software as a Service (SaaS)**: Delivers software applications over the internet on a subscription basis. Example: Microsoft 365, Netflix.
4. **Function as a Service (FaaS)**: Enables event-driven code execution without managing servers. Example: AWS Lambda.

---

### Deployment Models
1. **Public Cloud**: Services provided by third-party providers over the internet; accessible to anyone on a pay-as-you-go basis.
2. **Private Cloud**: Dedicated infrastructure for a single organization; offers greater control and security.
3. **Hybrid Cloud**: Combines public and private clouds for flexibility in deployment; ideal for disaster recovery and peak demand scenarios.

---

## Comparison Between Service Models
| Feature                | IaaS                | PaaS                | SaaS                | FaaS                |
|------------------------|---------------------|---------------------|---------------------|---------------------|
| User Control           | High (OS & apps)   | Medium (apps only)  | Low (app usage)     | None (event-driven) |
| Infrastructure Managed | By user            | By provider         | By provider         | By provider         |
| Examples               | AWS EC2, S3        | AWS Elastic Beanstalk | Microsoft 365       | AWS Lambda          |
